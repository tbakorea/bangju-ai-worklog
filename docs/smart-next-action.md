# 오늘의 다음 행동

본인 업무일지의 오늘 화면에서 지금 확인할 행동 한 가지, 선택 근거, 해당 기록을 여는 버튼을 제공한다. 일반 업무일지·피트니스 업무일지에 적용하며 기존 코칭을 새로 생성하는 기능이 아니라 기존 기록을 실행 순서로 연결하는 기능이다.

## 판단과 실행

- 15분 이내의 예정 일정 → 지원 필요·보류 업무 → 명시된 지난 기한/오늘 기한 → A 중요도 → PT 기록 차이 확인 → 다짐 시간표 연결 확인 → B/C/미지정 업무 → 남은 일정 순으로 기본 추천한다. 같은 범위는 일정 시각과 안정적인 식별자로 정렬한다. 점수는 행동 정렬 내부값이며 사람에 대한 점수가 아니다.
- 기한이 없는 이월 업무에 마감기한을 추정해 붙이지 않는다. 이미 완료·취소·위임한 업무, 미래로 연기한 업무, 완료/취소/노쇼/연기 처리된 수업은 새로 할 일로 제안하지 않는다. 지난 예약을 수업 누락이나 지각으로 판단하지 않는다.
- 지원 요청은 실행 강요 대신 막힌 점·필요한 지원 확인을 안내한다. 휴무·휴가에는 근무 설정 확인을 안내하고, 퇴근 기록이 있으면 결과·다음 근무 인수인계를 안내한다.
- `확인하기`: 해당 업무 행/시간표 행으로 이동해 포커스하거나 관련 보고서를 연다. 일정 추가, 완료, 근태, 급여, 메시지 발송을 자동으로 하지 않는다.
- `다른 제안`: 다른 후보 한 가지를 사용자가 선택해 볼 수 있다. 미루기나 완료로 저장하지 않는다. 원본 변경 시 후보를 다시 계산하며 완료한 후보는 빠진다.
- 짧은 카드, 긴 제목·근거는 두 줄 표시와 전체 설명 툴팁. 기존 입력칸을 재생성하지 않는다. 동일 추천은 DOM을 유지하고 카드 키보드 포커스를 보존한다.

## 원본과 권한

- 로그인·승인·오늘 날짜·본인 편집 가능 슬롯을 모두 확인한다. 대표/관리자가 다른 직원을 열람하는 화면, 센터 취합, 과거/미래, 미승인·로그아웃에는 제안을 표시하지 않는다. 일반 주간/월간/공통 페이지에도 표시하지 않는다.
- 현재 본인 일지의 업무·일정과 기존 본인 전날 PT 대조/시간표 등록 확인 API만 사용한다. 피트니스 자료 실패는 별도 확인 보류로 표시하며 이를 불일치/0건으로 바꾸지 않는다. 근무 종료·휴무에는 추가 조회를 하지 않는다.
- 추가 AI 서비스 호출 없이 브라우저의 명시적인 판단 규칙으로 계산한다. 업무 원문·회원정보를 추가 외부 서비스에 보내지 않는다. 본인이 이미 접근할 수 있는 기록만 사용한다.
- 새 API·DB 컬럼·권한·마이그레이션 없음. 추천 선택은 계정·직원·날짜별 메모리이며 로그인 변경 시 지운다. 원본 저장·불러오기와 기존 보고서는 유지한다.
- 공통 본인 식별 보완: `getEmployeeIdentityKeys`의 `id:` 접두사를 본인 매핑 슬롯 비교에도 적용했다. 기존 접두사 누락으로 실제 본인 슬롯임에도 코칭/확인 계정 ID를 찾지 못하던 경우를 수정했다. 타 직원의 직접 profile ID 처리와 조회 권한은 유지한다.

## 주요 파일

- `lib/smart-next-action.js`: 입력을 변경하지 않는 결정 규칙.
- `app.js`: 권한, 본인 기록 연결, 화면 갱신, 기존 행/보고서로 이동.
- `index.html`, `styles.css`: 일반/피트니스 카드와 반응형 배치.
- `scripts/smart-next-action*.cjs`: 판단·동작·레이아웃 회귀 검증.

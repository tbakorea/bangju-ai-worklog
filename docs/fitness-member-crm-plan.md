# 비욘드 피트니스 회원관리 DB 기획

## 목표

다짐에서 가져온 회원 운영자료와 동의 정보를 같은 운영 DB에서 연결해 재가입 안내, 상담 배정, 재연락 예약으로 이어지게 한다. 분석용 회원 DB는 별도로 복제하지 않는다.

## 데이터 구조

- `fitness_members`: 암호화한 이름·연락처·다짐 회원 ID, 담당 직원
- `member_consents`: 필수정보 이용, 광고성 정보, 문자·카카오·앱 푸시 동의와 철회
- `member_contracts`: 계약 기간, 만료일, PT 구매·잔여 횟수
- `member_attendance`: 회원 출석 이력
- `member_pt_sessions`: PT 일정·결과·잔여 횟수
- `member_followups`: 재가입 후보, 담당 직원, 연락 예정일, 상담 결과
- `member_message_logs`: 채널, 암호화한 발송 내용, 성공 여부, 수신거부
- `member_contact_audit_logs`: 연락처 열람과 변경 감사기록

## 권한과 안전장치

- 일반 직원·인포·트레이너는 본인에게 배정된 회원만 서버 API에서 조회한다.
- 센터장·대표만 전체 회원과 동의 원본을 관리한다.
- 브라우저에서 DB 직접 조회를 차단하고, 연락처는 기본적으로 마스킹한다.
- 연락처 열람은 감사기록을 남기며 일괄 다운로드 API를 제공하지 않는다.
- 동의 철회 또는 광고성 정보 미동의 시 대기 중인 후속업무를 DB 트리거가 즉시 취소한다.
- 다짐 동의는 동의문 버전과 증빙 위치가 확인된 경우에만 광고성 수신 동의로 인정한다.

## 적용 순서

1. `supabase/worklog_schema.sql`을 운영 DB에 적용한다.
2. 서버에 `SUPABASE_SERVICE_ROLE_KEY`, `MEMBER_CONTACT_ENCRYPTION_KEY`를 비밀 환경변수로 등록한다.
3. 다짐 수집기가 회원·계약·출석·PT 테이블을 외부 ID 기준으로 중복 없이 갱신한다.
4. 앱의 AI 후보 결과를 `member_followups`의 재가입·상담·재연락 업무로 생성한다.

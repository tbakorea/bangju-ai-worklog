# 업무일지 날짜·현장별 날씨

## 참고 구현과 적용

읽은 파일: `/Users/bangju/Documents/비욘드 플래너/dashboard/app.js`, `dashboard/styles.css`.
플래너의 날짜별 기록 선택, 누락값과 0도를 구분하는 기온 변환, 아이콘·기온 범위와 툴팁을 분리하는 패턴을 재사용했다.
플래너의 기본 울산 좌표와 브라우저 위치는 가져오지 않았다. 미래 예보는 선택 날짜와 현장의 명시적 조회 결과만 사용한다.

방주의 기존 현장 주소 설정·좌표 조회와 `worklog_states.state.weatherCache`를 유지한다.
키는 `YYYY-MM-DD::현장`, 원장은 로그인 사용자의 기존 날짜별 행이다. 새로운 테이블이나 컬럼은 없다.
기존 주요 지역 주소 매핑을 재사용하며, 분류되지 않은 현장은 다른 현장의 '기타' 주소를 상속하지 않는다.

오늘은 당일 날씨, 미래는 해당 날짜의 일별 예보를 조회한다. 예보 범위는 오늘 포함 16일이며, 범위 밖은 '예보 대기'로 표시한다.
과거에 저장된 정상 기록은 보존하고, 기록이 없거나 예보로 남아 있으면 날짜별 과거 자료를 조회한다. 자료를 제공하지 않거나 조회가 실패하면 기존 기록을 보존하고, 기록이 없으면 '기록 없음'으로 표시한다.
응답 날짜·사용자·주소가 요청과 일치할 때만 저장한다. 요청 도중 선택 날짜가 바뀌어도 원래 날짜로 저장한다.
JSON 기록의 recordType으로 forecast/day/history를 구분한다. 기존 JSONB 원장을 사용하므로 DB 마이그레이션은 없다. 예보는 그날이 오늘이 되면 당일 자료로 다시 조회한다.
화면은 과거·미래 모두 아이콘과 최저/최고 기온만 표시하며 예보 여부는 툴팁·접근성 설명으로 알린다. DB 읽기에 성공하면 그 날짜의 로컬 날씨를 DB 기록으로 교체하며, DB에 없으면 로컬 잔여값도 사용하지 않는다.
주소 변경은 좌표 캐시만 무효화하고 과거 날씨를 지우지 않는다.
조회 실패, 날짜 불일치, 불완전한 응답은 정상 기록을 덮어쓰지 않는다. 일부 기온만 있는 최초 기록은 누락 부분을 '—'로 표시한다.

## 검증

- `./scripts/qa-check.sh`: 통과 (정적 검사, 100명 × 90일 시뮬레이션).
- `git diff --check`: 통과.
- `scripts/weather-browser-qa.cjs`: Chrome 390/820/1440px 통과.
  - 0도·영하·빈 문자열·null·undefined와 일부 기온 누락.
  - 조회 중 날짜 이동, 저장된 과거 기록 덮어쓰기 차단, 현장 간 분리.
  - 과거 자료 조회·미래 예보 저장, 예보에 다른 날짜 current 값 사용 차단, 예보 범위 제한.
  - 예보 DB 저장·새 문서에서 복원, 오늘이 된 예보의 갱신 조건.
  - 실패·응답 날짜 불일치·기온 누락으로 기존 정상 기록을 덮어쓰지 않음.
  - 업무일지의 실제 saveRemoteSnapshot으로 저장한 행을 새 문서에서 실제 loadRemoteWorklogForActiveDate로 복원.
  - 저장된 과거 날짜 / 기록 없음 화면 전환, 주소 변경 시 기록 보존.
  - 아이콘·범위 한 줄 및 칩 경계, 휴대폰 날짜 제목 잘림 확인. 세 화면 스크린샷 확인.
- `./scripts/mobile-browser-qa.sh`: 기존 퇴사 직원 김영채를 현재 피트니스 명단에서 찾는 회귀 테스트에서 중단.
  오류: `representative fitness view should load Kim Young-chae's profile-user worklog`.
  날씨 전용 테스트로 이번 범위를 별도 검증했다. 기존 퇴사 정책이나 해당 테스트는 변경하지 않았다.

날씨 브라우저 테스트는 로컬 서버(기본 http://127.0.0.1:8782/index.html)가 필요하다.
Node에 Playwright가 설치된 환경에서 `node scripts/weather-browser-qa.cjs`로 실행한다.
외부 날씨 응답과 DB 전송은 모의 처리한다. 운영 사용자 원장을 테스트 데이터로 수정하지 않았으며, 운영 계정의 실제 날씨 저장·재접속은 이 검사에 포함되지 않는다.

예보 범위 확인: [Open-Meteo 공식 문서](https://open-meteo.com/en/docs) (2026-10-30).

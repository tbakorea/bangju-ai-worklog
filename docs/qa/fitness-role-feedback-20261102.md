# 피트니스 역할별 개선 피드백 검증

## 변경 범위

- 오늘의 개인·센터 보고서에 역할·당일 기록 분류·본인 실행 반응을 연결한 피드백.
- 이전 실행 미완료·완료·지원·보류·관리자 반복 확인에 따른 분기.
- 완료 자기보고와 관리자 확인을 구분하고 날짜 경과만으로 단계가 오르지 않음.
- 기존 실행기록 JSON에 버전·역할·단계·표준 과제 키만 추가. 별도 DDL/권한 변경 없음.
- AI 입력 허용 목록을 브라우저·API에서 각각 적용. 금액·회원·회사 원문 제외.
- 보고서 비동기 갱신 시 미저장 입력 보호, 사용자 전환 시 늦은 응답 제외.
- 개인·센터 출력 높이 보완. 과거 보고서의 기존 코칭 미표시 동작 유지.

## 결과

- `node --test scripts/fitness-role-feedback.test.cjs`: 7개 테스트 통과.
  - 역할 우선순위, 비관리자 기본값, 날짜·매출에 의한 가짜 진전 방지.
  - 진행·완료·지원·보류·반복 확인 분기, 동일 날짜 반복 저장의 단계 증가 방지.
  - 미래·다른 역할 기록 제외, 확인 전 상태, 관리자 확인 조건.
  - AI 입력의 원문·금액 제외 및 API가 제공자에게 보내는 실제 본문 검증.
- `node scripts/fitness-role-feedback-browser-qa.cjs`: 390·820·1440px 모두 통과.
  - 본인·동료 차단·위임 조회, 날짜 필터, 오류·재조회·세션 캐시 격리.
  - 단계 재구성, 맞춤 실행 구분, 저장 함수의 실제 요청 본문·결과 기록 검증.
  - 미저장 지원 설명 보존, AI의 추가 숫자 목표 차단.
  - 개인·센터 보고서 및 긴 AI 문구를 포함한 내보내기의 하단 잘림 없음.
- `./scripts/qa-check.sh`: 정적 검사 및 100명 × 90일 시뮬레이션 통과.
- `git diff --check`: 통과.
- `./scripts/mobile-browser-qa.sh`: 실행했으나 기존
  `representative fitness view should load Kim Young-chae's profile-user worklog`
  검증에서 중단. 전체 QA 통과로 기록하지 않음.
  동일 실패는 변경 전 `dagym-unattended-20261101.md`와
  `dagym-screen-lock-20261101.md`에도 기록돼 있음.
  퇴사 직원 노출 동작이나 해당 기존 테스트를 이번 기능에 맞춰 우회하지 않음.

AI 생성·DB 저장을 수행한 검증과는 구분한다.

# 직원 보고서의 운영 요약과 긍정 피드백

## 변경 이유

일반 직원은 센터의 매출 원본을 직접 읽는 권한이 없어 개인 보고서의 전일 매출 계산이 계속 `산출 대기`로 남았다. 직원 보고서에는 역할 수행에 도움이 되는 비금융 운영 요약과 본인 기록에 근거한 피드백을 표시한다. 권한을 넓히거나 누락값을 실적으로 만들지 않는다.

## 동작

- 일반 직원 개인 보고서: `전일 운영 · 나의 좋은 기록`. 날짜가 확인된 전일 방문·PT 예약 집계, 오늘의 기록, 다음 한 걸음을 표시한다. 돈·원장·회원 명단·연락처는 요약 API 응답에 포함하지 않는다.
- 새 API는 로그인 사용자와 승인된 피트니스 소속(또는 대표)을 서버 DB로 확인한다. 센터는 beyond-fitness로 고정하고 선택 보고일의 정확한 전날만 조회한다. 요청에서 역할/금액 필드/다른 직원 ID를 바꿔도 응답 범위를 넓히지 않는다. 기존 DB RLS 및 원본 접근 권한 변경 없음.
- 출석은 정상 소스·인증·일별 범위 검증이 있는 값만 사용한다. 확인된 0은 0, 미확인 값은 —. 시간표 행이 없다는 이유만으로 합성된 예약 0은 제외한다.
- 피드백은 본인 업무일지의 상담·PT·완료 표시·홍보·시간표·우선업무·지원 요청 기록으로 만든다. 예: `오늘 상담 1건을 기록했습니다. 다음 안내를 이어갈 근거를 남기셨습니다.` 상담의 실제 효과·등록 전환·개선 성과를 확인 없이 칭찬하지 않는다.
- 인포는 남은 질문·다음 안내 시점, 트레이너는 실제 수업 결과·다음 운동 약속 등 가능한 행동 한 가지를 제안한다. 기록이 없으면 작은 기록부터 시작하도록 안내한다. 지원 요청은 함께 해결할 근거로 격려한다. 추가 AI 호출이나 임의 목표·자동 업무 배정 없음.
- 센터장 개인 보고서: 실제 저장 자료로 계산한 전일 매출을 유지한다. 같은 월의 확인된 월누계 두 개로 계산하며, 비교 자료가 없으면 확인된 월누계를 `월누계 매출`이라고 표시한다. 월누계를 일매출로 표시하거나 추정 집계기간으로 차감하지 않는다. 음수 정정 차액을 0으로 바꾸지 않는다.
- 보고서 열기 시 갱신, 내보내기 시 조회 대기. 계정·날짜별 메모리 캐시, 계정 변경/로그아웃 시 삭제. 날짜 불일치·계정 전환 응답 폐기. 재조회 실패는 기존 확인 집계 보존 및 재조회 보류 표시. 첫 조회 실패 시 —와 본인 기록 피드백을 함께 표시한다.
- 화면·PNG·PDF·인쇄·공유 텍스트에 반영한다. 피드백 문단은 줄바꿈해 표시하고 출력 높이를 확보한다. 기존 미션·역할별 코칭·원본 저장 동작 유지. 새 DB 구조 없음.

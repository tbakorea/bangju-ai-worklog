# 전날 PT 시간표 대조와 기록 보완 안내

## 동작

- 트레이너·센터장 등 PT 담당자의 본인 피트니스 업무일지 보고서 하단에 `전날 PT 시간표 대조 · 확인과 보완` 표시.
- 선택한 보고일의 한국시간 전날을 계산한다. 월말·연말도 날짜 기준으로 조회한다.
- DB의 다짐 원본 `dagym_pt_schedule_events.scheduled_at/session_type`와 본인의 전날 최신 저장 `worklog_states.state.ownerWorklog.schedule`를 대조한다. 현재 일정 자동 투영본을 비교 대상으로 대체하지 않는다.
- 다짐 수업 ID가 있는 일정은 ID를 우선 매칭하고 시작 시각·유료/무료 구분을 비교한다. 업무일지 수정 이력이 있어도 다짐 원본을 덮어쓴 것으로 간주하지 않는다.
- 직접 입력한 일정은 시작 시각·유료/무료 구분을 일대일로 소비해 대조한다. 회원명 없이 시간만 대조하는 기능이다. 연결 ID 없는 서로 다른 시간의 수업을 같은 회원의 변경 수업으로 추정해 묶지 않는다.
- 대응 일정 미확인, 시작 시각 변경, 유료/무료 구분 차이, 다짐 연결 미확인 일정을 구분한다. 예: `유료PT · 다짐 16:00 ↔ 업무일지 17:30 (무료PT)`.
- 취소·노쇼·연기는 수업 누락/불성실 판정에서 제외하고 별도 확인 항목에 표시한다. 예약과 수업 완료를 동일하게 판단하지 않는다.
- 변경·취소·노쇼·대체강사 여부 확인 → 실제 시간과 사유 보완 → 필요한 원본 변경은 센터장 확인 순서로 안내한다. 수업 완료·급여·근태·인사평가를 변경하지 않는다.

## 데이터와 접근

- 서버 인증 및 승인 상태, 피트니스 소속, PT 담당 직무 확인. 클라이언트에서 보낸 trainer/owner는 사용하지 않는다. 인증한 본인 profile ID로만 다짐·일지를 조회한다.
- 회원명·연락처·암호화 회원명·상세 원문은 조회/응답에 포함하지 않는다. 원본 수업 ID도 응답하지 않는다. 시간·구분·확인 문구만 보고서에 반영한다. AI 입력에 추가하지 않는다.
- 타 직원·센터 취합 보고서에는 표시하지 않는다. 기존 대표·관리자 열람 범위나 RLS를 확장하지 않는다.
- 전날 일지 없음, 강사 연결된 다짐 행 없음, 전날 마감 이후 수집 확인 불가, 조회 실패는 `대조 확인 불가`로 구분한다. 수업 0건/일치/누락으로 단정하지 않는다.
- 현재 DB에는 일자별 시간표 전체수집·빈 시간표 확정 이력이 없다. 따라서 다짐 행이 없는 날은 휴무나 0건으로 확정할 수 없다. 존재하는 최신 행의 대조 결과도 전체 수집 완전성 판정이 아님을 명시한다.
- 시작 시각만 비교하며 종료 시각·수업 길이는 판정하지 않는다. 기존 일지 항목에 신뢰할 수 있는 종료 시각이 일관되게 저장되지 않기 때문이다.
- 본인·보고일별 메모리 캐시 60초, 보고서 재열기 시 갱신. 계정 변경/로그아웃 시 삭제하고 비동기 계정 전환 응답을 폐기한다. 보고서와 기존 이미지·PDF·공유에 같은 내용을 포함한다.
- 기존 DB 읽기만 수행하므로 마이그레이션 없음. 기존 서버 서비스 키를 사용하며 사용자 화면에 노출하지 않는다.

## 운영 확인

2026-11-02 읽기 전용 검증에서 전날 11월 1일은 조회 가능한 다짐 수업 행이 없었다. 대조 성공이나 불일치를 만들지 않고 두 PT 담당 계정 모두 대조 보류로 분류됨을 확인했다. 운영 원본에 테스트 자료는 쓰지 않았다.

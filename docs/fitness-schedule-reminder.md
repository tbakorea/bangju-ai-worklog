# 센터장·트레이너 시간표 작성 독려

- 본인 피트니스 업무일지 보고서를 열 때 선택한 날짜의 다짐 시간표 연결 여부를 조회한다. 대상은 센터장·트레이너·강사·코치 및 명시적 PT 수업 담당자이며, 인포의 PT 상담 안내만으로 대상이 되지 않는다. 과거 보고서에는 등록 독려를 추가하지 않는다.
- 서버는 기존 인증·승인·피트니스 직무 검증을 거쳐 인증 사용자 profile ID의 활성 시간표만 조회한다. 원본 날짜 또는 업무일지 수정본 날짜 중 선택일과 일치하는 등록 내역이 있으면 안내를 숨긴다. 취소·노쇼로 남은 수업도 작성된 시간표로 인정한다.
- 성공한 DB 조회에서 연결 행이 없을 때 `동기화된 자료에서 본인에게 연결된 수업 일정이 확인되지 않습니다`라고 알린다. 이는 외부 다짐 원본의 빈 시간표 확정이나 수업 0건 판정이 아니다. 예정 수업이 있으면 다짐에 먼저 작성하고, 이미 작성했다면 강사 연결·동기화를 확인하도록 안내한다. 최신 수집 전체완료를 증명하는 일자별 이력은 아직 없으므로 원본 0건을 단정하지 않는다.
- 조회 실패는 별도 확인 보류로 표시하며 독려 토스트를 띄우지 않는다. 휴무·비번·휴가·병가·휴직·퇴사·미참여는 독려 제외. 휴무일 실제 대체근무가 기록된 경우 근무 상황에 따라 판단한다.
- `푸쉬`는 보고서 안내 카드와 앱 실행 중 토스트로 구현했다. 오늘 보고서에서만 계정·날짜·브라우저별 하루 한 번 토스트를 표시한다. 로컬 저장소에 알림 표시 여부만 저장해 새로고침 시에도 반복하지 않는다. 저장소가 불가하면 메모리 기준으로 중복을 막는다. 미래 보고서는 카드만 표시한다. OS/웹 푸시, 이메일·문자 발송은 추가하지 않는다.
- 시간표를 등록하고 동기화한 뒤 보고서를 다시 열면 안내가 사라진다. 보고서 재열기 시 강제 조회, 일반 재사용은 60초 캐시. 타 직원·센터 취합 보고서에는 표시하지 않으며 계정 전환 응답을 폐기한다.
- 이미지·PDF·공유·인쇄에도 안내를 포함한다. 기존 전날 PT 대조는 유지한다. 원본·업무일지·근태·급여를 변경하거나 AI에 알림 자료를 보내지 않는다. 신규 DB 구조 없음.

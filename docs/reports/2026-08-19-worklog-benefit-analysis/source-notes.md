# 업무일지 도입 효과 분석 — 소스 노트

- 질문: 직원의 앱 사용 이후 개선된 부분과 회사 차원의 실제 유익이 있는지 확인한다.
- 기준일: 2026년 8월 19일. 당일은 진행 중이므로 기간 비교에서 제외했다.
- 모집단: 승인된 직원 11명과 `public.worklog_states`의 직원·날짜 단위 179행.
- 실제 사용: 우선업무, 시간별 일정, 보고, 메모, 출퇴근 중 하나 이상 의미 있는 값이 있는 기록으로 정의했다.
- 완료 업무: 상태가 완료·취소·위임·연기이거나 완료 플래그가 설정된 우선업무로 정의했다.
- 출퇴근 완결: 출근과 퇴근 시간이 모두 존재하는 기록으로 정의했다.
- 수기 이관 제외: `manualImports`에 `fitness-paper-*` 출처가 있는 20행은 앱 자체 사용량과 분리했다.
- 비교 구간: 첫 안정 운영 주중(8월 10~14일)과 최근 완료 주중(8월 17~18일). 후자는 2일뿐이므로 방향성만 판단한다.
- 시각화 선택: 비교 기간 길이가 5일 대 2일로 달라 추세선은 사용하지 않았다. 네 지표의 비율을 두 기간으로 나눈 묶음 막대와 정확한 비교표를 함께 사용했다.
- 조직명 품질: `(주)비욘드 컴퍼니`와 `(주)비욘드컴퍼니`가 별도 값으로 존재해 조직별 합산은 정규화 전 참고치로만 사용했다.
- 인과 한계: 앱 도입 전 동일 정의의 기준값, 관리자 검토시간, 급여 정정건수, 매출 귀속 자료가 없어 재무 ROI나 생산성 향상을 인과적으로 확정할 수 없다.
